## Function 1: Add Waste Record

Adds a new waste record to the system.

**Example:**
```javascript
waste.addWasteRecord(1, "Plastic", 12, "Recycling", "2026-11-15");
```

**Parameters:**
- `organisationid`: Organisation ID
- `wastetype`: Type of waste
- `quantity`: Amount of waste in kg
- `disposalmethod`: Disposal method
- `daterecorded`: Date of the record

**Expected output:**
> Record added.

## Function 2: Filter Waste Record by Type

Retrieves waste records based on their waste type.

**Example:**
```javascript
waste.filterWasteRecordByType("Plastic");
```

**Parameter:**
- `wastetype`: Type of waste to search for

**Expected output:**

Returns an array containing all Plastic waste records.

## Function 3: Get Waste by Date Range

Retrieves waste records within a specified date range.

**Example:**
```javascript
waste.getWasteByDateRange("2026-11-01", "2026-11-07");
```

**Parameters:**
- `startDate`: Starting date
- `endDate`: Ending date

**Expected output:**

Returns an array containing waste records from 1 November to 7 November 2026.

## Function 4: Calculate Waste by Organisation

Calculates the total waste generated by an organisation and separates it by disposal method.

**Example:**
```javascript
waste.calculateWasteByOrganisation(1);
```

**Parameter:**
- `organisationid`: ID of the organisation

**Expected output:**
```javascript
{
    Organisation: "ABC Company",
    "Total Waste": 50,
    "Total Recycled": 25,
    "Total Landfill": 20,
    "Total Composted": 5
}
```
